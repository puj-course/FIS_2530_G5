## 🌍 Descripción del Proyecto  

**Greenet** es una aplicación que promueve el **intercambio, reuso y reciclaje de recursos** dentro de comunidades locales.  

Nuestro objetivo es:
- 🌱 Reducir el consumo innecesario.  
- 🤝 Fomentar prácticas sostenibles.  
- 🏘️ Fortalecer la colaboración comunitaria.  

Además, Greenet contribuye al **ODS 11: Ciudades y comunidades sostenibles** ✨

## ⚙️ Instalación y Ejecución  

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/puj-course/FIS_2530_G5.git
   cd FIS_2530_G5
2. **Importar el proyecto en tu IDE (VSCode o IntelliJ):**
   - Asegúrate de tener Java 17+ y JavaFX configurado.
   - Configura las librerías JDBC para conexión a base de datos H2 embebida.
3. **Ejecutar la aplicación:**
   - Inicia la clase principal Main.java.
   - Se abrirá la ventana principal de Greenet.
